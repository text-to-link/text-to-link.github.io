Un creador de enlaces gratuito a partir de texto

Text to Link es un creador de enlaces gratuito a partir de texto. Escribe las palabras que quieres mostrar, pega la dirección y obtén un enlace listo para usar en HTML, Markdown, BBCode, reStructuredText, AsciiDoc, Slack, Textile u Org-mode. Sirve para blogs, correos, firmas de foros, documentación y perfiles sociales: en cualquier lugar donde una URL sin formato quede desordenada.

Funciona como generador de enlaces de texto, de texto para URL y de enlaces para artículos: añade un título, abre el enlace en una pestaña nueva, márcalo como nofollow, sponsored o ugc, elimina utm_ y otros parámetros de rastreo y cópialo como enlace formateado que se pega como texto clicable en Gmail, Google Docs, Notion o Slack.

¿Necesitas varios enlaces? Pega un párrafo entero en el modo «Convertir URL en enlaces» y cada URL se volverá un enlace, o usa «Varios enlaces» para convertir líneas «texto | url» en una lista HTML lista para usar. Todo funciona en tu navegador, así que el texto y las URL que escribes nunca se suben.

Cómo enlazar a un texto resaltado de una página

Un enlace con resaltado, o enlace a fragmento de texto, abre una página, se desplaza hasta un pasaje y lo marca. Abre las opciones avanzadas, busca «Resaltar texto en la página», escribe las palabras exactas que quieres resaltar y el generador añade #:~:text= a tu URL.

Para resaltar un pasaje más largo, rellena el campo «hasta»: el navegador marca todo desde las palabras iniciales hasta las finales. Si las mismas palabras aparecen varias veces, usa «Coincidencia exacta» para añadir el texto que va justo antes o después. Puedes añadir varios resaltados a un enlace.

Los enlaces con resaltado funcionan en Chrome, Edge, Safari 16.1+ y Firefox 131+. En otros navegadores el enlace abre la página igualmente, solo que sin resaltar. El texto debe estar visible en la página y coincidir exactamente, sin distinguir mayúsculas de minúsculas.

https://example.com/article#:~:text=quick%20brown,lazy%20dog

Preguntas frecuentes

¿Cómo convierto texto en un enlace?

Escribe el texto del enlace, pega la URL, elige HTML, Markdown u otro formato y pulsa Copiar. El texto será la parte clicable del enlace.

¿Qué diferencia hay entre enlaces HTML, Markdown y BBCode?

Los enlaces HTML se usan en páginas web y plantillas de correo, los de Markdown en GitHub, Reddit, Notion y documentación, y los de BBCode en muchos foros.

¿Cómo enlazo a un texto resaltado de una página web?

Abre las opciones avanzadas, escribe las palabras a resaltar en «Resaltar texto en la página» y copia el resultado. El enlace termina en #:~:text= seguido de tu texto, y los navegadores compatibles se desplazan hasta él y lo resaltan.

¿Puedo quitar utm y otros parámetros de rastreo de una URL?

Sí. En las opciones avanzadas elige «Quitar solo rastreo» para eliminar utm_*, fbclid, gclid y similares, o quita todo lo que sigue al signo de interrogación.

¿Cómo pego un enlace clicable en Gmail o Google Docs?

Pulsa «Copiar como enlace» y pega. El texto llega ya clicable, sin código que editar.

¿Puedo abrir el generador con los campos ya rellenados?

Sí. Añade los parámetros a la dirección: ?url=https://example.com&text=Mi%20enlace&fmt=markdown. En el móvil también puedes instalar el sitio como app y compartir una página directamente con ella.

¿Puedo crear un código QR para mi enlace?

Sí. Pulsa «Código QR» bajo el resultado, escanéalo para comprobar el enlace y descárgalo como SVG o PNG. Se genera en tu navegador.

¿Funciona sin conexión?

Sí. Tras la primera visita el navegador guarda el sitio, así que puedes crear enlaces sin conexión. Solo la analítica opcional y la vista previa de otros sitios necesitan internet.

¿La herramienta es gratuita y privada?

Sí. Es gratuita, no requiere registro y todo funciona en tu navegador: el texto y las URL que escribes nunca se envían a un servidor. La analítica solo se activa si la aceptas.
