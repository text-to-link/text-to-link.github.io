Um criador de links gratuito a partir de texto

O Text to Link é um criador de links gratuito a partir de texto. Digite as palavras que quer mostrar, cole o endereço e receba um link pronto em HTML, Markdown, BBCode, reStructuredText, AsciiDoc, Slack, Textile ou Org-mode. Serve para blogs, e-mails, assinaturas de fóruns, documentação e perfis sociais: em qualquer lugar onde uma URL pura fique feia.

Ele funciona como gerador de links de texto, de texto para URL e de links para artigos: adicione um título, abra o link em uma nova guia, marque como nofollow, sponsored ou ugc, remova utm_ e outros parâmetros de rastreamento e copie como link formatado que cola como texto clicável no Gmail, Google Docs, Notion ou Slack.

Precisa de mais de um link? Cole um parágrafo inteiro no modo «Transformar URLs em links» e cada URL vira um link, ou use «Vários links» para transformar linhas «texto | url» em uma lista HTML pronta. Tudo roda no seu navegador, então o texto e as URLs que você digita nunca são enviados.

Como criar um link para um trecho destacado da página

Um link com destaque, também chamado de link para fragmento de texto, abre uma página, rola até um trecho e o marca. Abra as opções avançadas, encontre «Destacar texto na página», digite as palavras exatas que quer destacar e o gerador adiciona #:~:text= à sua URL.

Para destacar um trecho mais longo, preencha o campo «até»: o navegador marca tudo, das palavras iniciais às finais. Se as mesmas palavras aparecem mais de uma vez, use «Correspondência exata» para adicionar o texto que vem logo antes ou depois. Você pode adicionar vários destaques a um link.

Links com destaque funcionam no Chrome, Edge, Safari 16.1+ e Firefox 131+. Em outros navegadores o link ainda abre a página, só que sem destaque. O texto precisa estar visível na página e coincidir exatamente, sem diferenciar maiúsculas de minúsculas.

https://example.com/article#:~:text=quick%20brown,lazy%20dog

Perguntas frequentes

Como converter texto em link?

Digite o texto do link, cole a URL, escolha HTML, Markdown ou outro formato e clique em Copiar. O texto vira a parte clicável do link.

Qual é a diferença entre links HTML, Markdown e BBCode?

Links HTML são usados em páginas web e modelos de e-mail, os de Markdown no GitHub, Reddit, Notion e em documentação, e os de BBCode em muitos fóruns.

Como criar um link para um trecho destacado de uma página?

Abra as opções avançadas, digite as palavras a destacar em «Destacar texto na página» e copie o resultado. O link termina com #:~:text= seguido do seu texto, e os navegadores compatíveis rolam até ele e o destacam.

Posso remover utm e outros parâmetros de rastreamento de uma URL?

Sim. Nas opções avançadas escolha «Remover só rastreamento» para eliminar utm_*, fbclid, gclid e similares, ou remova tudo após o ponto de interrogação.

Como colar um link clicável no Gmail ou no Google Docs?

Clique em «Copiar como link» e cole. O texto chega já clicável, sem código para editar.

Posso abrir o gerador com os campos já preenchidos?

Sim. Adicione os parâmetros ao endereço: ?url=https://example.com&text=Meu%20link&fmt=markdown. No celular você também pode instalar o site como aplicativo e compartilhar uma página diretamente com ele.

Posso criar um QR code para o meu link?

Sim. Clique em «QR code» abaixo do resultado, escaneie para conferir o link e baixe como SVG ou PNG. Ele é gerado no seu navegador.

Funciona offline?

Sim. Depois da primeira visita o navegador guarda o site, então você pode criar links sem conexão. Só a análise opcional e a pré-visualização de outros sites precisam de internet.

A ferramenta é gratuita e privada?

Sim. É gratuita, não exige cadastro e tudo roda no seu navegador: o texto e as URLs que você digita nunca são enviados a um servidor. A análise só é ativada se você aceitar.
