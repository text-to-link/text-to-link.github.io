So machen Sie aus Text einen Link

  1. Linktext eingebenGeben Sie die Wörter ein, die Nutzer sehen und anklicken sollen, zum Beispiel „Den ganzen Artikel lesen“.
  2. URL einfügenFügen Sie die Adresse hinzu. Fehlt https://, ergänzen wir es, und auf Wunsch entfernen wir Tracking-Parameter.
  3. Format wählen und kopierenWählen Sie HTML, Markdown, BBCode, reST, AsciiDoc, Slack, Textile oder Org und kopieren Sie den Code oder einen formatierten Link zum Einfügen in E-Mails und Dokumente.

Ein kostenloser Link-Generator für Text

Text to Link ist ein kostenloser Link-Generator für Text. Geben Sie die gewünschten Wörter ein, fügen Sie die Adresse ein und erhalten Sie einen fertigen Link als HTML, Markdown, BBCode, reStructuredText, AsciiDoc, Slack, Textile oder Org-mode. Ideal für Blogbeiträge, E-Mails, Forensignaturen, Dokumentation und Social-Media-Profile – überall dort, wo eine nackte URL unordentlich aussieht.

Das Tool dient als Textlink-Generator, URL-Text-Generator und Artikellink-Generator: Fügen Sie einen Titel hinzu, öffnen Sie den Link in einem neuen Tab, markieren Sie ihn als nofollow, sponsored oder ugc, entfernen Sie utm_ und andere Tracking-Parameter und kopieren Sie ihn als formatierten Link, der sich in Gmail, Google Docs, Notion oder Slack als klickbarer Text einfügen lässt.

Sie brauchen mehrere Links? Fügen Sie im Modus „Text verlinken“ einen ganzen Absatz ein, und jede URL darin wird zum Link, oder nutzen Sie „Mehrere Links“, um Zeilen im Format „Text | URL“ in eine fertige HTML-Liste zu verwandeln. Alles läuft in Ihrem Browser, daher werden Ihr Text und Ihre URLs nie hochgeladen.

So verlinken Sie auf markierten Text einer Seite

Ein Hervorhebungs-Link, auch Textfragment-Link genannt, öffnet eine Webseite, scrollt zu einer Passage und markiert sie. Öffnen Sie die erweiterten Optionen, suchen Sie „Text auf der Seite hervorheben“, geben Sie die genauen Wörter ein, die Sie hervorheben möchten, und der Generator hängt #:~:text= an Ihre URL an.

Um eine längere Passage hervorzuheben, füllen Sie das Feld „bis“ aus: Der Browser markiert alles vom Anfangs- bis zum Endtext. Kommen dieselben Wörter mehrmals vor, nutzen Sie „Genauer Treffer“, um den Text direkt davor oder danach anzugeben. Sie können einem Link mehrere Hervorhebungen hinzufügen.

Hervorhebungs-Links funktionieren in Chrome, Edge, Safari 16.1+ und Firefox 131+. In anderen Browsern öffnet der Link die Seite trotzdem, nur ohne Hervorhebung. Der Text muss auf der Seite sichtbar sein und genau übereinstimmen, wobei die Groß- und Kleinschreibung keine Rolle spielt.

https://example.com/article#:~:text=quick%20brown,lazy%20dog

Häufig gestellte Fragen

Wie wandle ich Text in einen Link um?

Geben Sie den Linktext ein, fügen Sie die URL ein, wählen Sie HTML, Markdown oder ein anderes Format und klicken Sie auf „Kopieren“. Der Text wird zum klickbaren Teil des Links.

Was ist der Unterschied zwischen HTML-, Markdown- und BBCode-Links?

HTML-Links werden auf Webseiten und in E-Mail-Vorlagen verwendet, Markdown-Links auf GitHub, Reddit, Notion und in Dokumentationen, BBCode-Links in vielen Foren.

Wie verlinke ich auf markierten Text einer Webseite?

Öffnen Sie die erweiterten Optionen, geben Sie unter „Text auf der Seite hervorheben“ die Wörter ein und kopieren Sie das Ergebnis. Der Link endet mit #:~:text= gefolgt von Ihrem Text, und unterstützende Browser scrollen dorthin und markieren ihn.

Kann ich utm- und andere Tracking-Parameter aus einer URL entfernen?

Ja. Wählen Sie in den erweiterten Optionen „Nur Tracking entfernen“, um utm_*, fbclid, gclid und ähnliche Parameter zu entfernen, oder entfernen Sie alles nach dem Fragezeichen.

Wie füge ich einen klickbaren Link in Gmail oder Google Docs ein?

Klicken Sie auf „Als formatierten Link kopieren“ und fügen Sie ihn ein. Ihr Text erscheint bereits klickbar, ohne dass Sie Code bearbeiten müssen.

Kann ich den Generator mit bereits ausgefüllten Feldern öffnen?

Ja. Hängen Sie die Parameter an die Adresse an: ?url=https://example.com&text=Mein%20Link&fmt=markdown. Auf dem Smartphone können Sie die Website außerdem als App installieren und eine Seite direkt dorthin teilen.

Kann ich einen QR-Code für meinen Link erstellen?

Ja. Klicken Sie unter dem Ergebnis auf „QR-Code“, scannen Sie ihn, um den Link zu prüfen, und laden Sie ihn als SVG oder PNG herunter. Er wird in Ihrem Browser erzeugt.

Funktioniert es offline?

Ja. Nach dem ersten Besuch speichert Ihr Browser die Website, sodass Sie auch ohne Verbindung Links erstellen können. Nur die optionale Analyse und die Vorschau anderer Websites benötigen das Internet.

Ist das Tool kostenlos und privat?

Ja. Es ist kostenlos, erfordert keine Anmeldung und alles läuft in Ihrem Browser: Der eingegebene Text und die URLs werden nie an einen Server gesendet. Die Analyse wird nur aktiviert, wenn Sie zustimmen.
