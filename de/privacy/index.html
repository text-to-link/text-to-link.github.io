Datenschutzerklärung

Zuletzt aktualisiert: 2026-10-29

Kurzfassung

Text to Link läuft in Ihrem Browser. Der eingegebene Text und die URLs werden auf Ihrem Gerät verarbeitet und nie an einen Server gesendet. Es gibt keine Konten und keine Werbung.

Was auf Ihrem Gerät gespeichert wird

Ihr Browser speichert für diese Website einige kleine Einträge: Ihr Design (ttl-theme), Ihr Ausgabeformat und Ihre Optionen, jedoch nicht Ihren Text (ttl-settings), sowie Ihre Auswahl zur Analyse (ttl-consent).

Die Website wird außerdem im Service-Worker-Cache Ihres Browsers gespeichert, damit sie ohne Verbindung geöffnet werden kann. Sie können all das jederzeit entfernen, indem Sie die Websitedaten in den Browsereinstellungen löschen.

Analyse

Wir verwenden Google Analytics 4, um Besuche zu zählen und zu sehen, welche Tools, Sprachen und Länder genutzt werden. Der von Ihnen eingegebene Text und die URLs werden dabei nie übermittelt. Werbefunktionen und personalisierte Anzeigen sind deaktiviert.

Der Analyse-Speicher ist standardmäßig verweigert. Solange Sie nicht auf „Akzeptieren“ klicken, werden keine Analyse-Cookies gesetzt. Das Google-Tag wird dennoch von googletagmanager.com geladen, sodass Ihr Browser Google kontaktiert und Google Ihre IP-Adresse sehen kann; außerdem kann Google anonyme Pings ohne Cookies oder Kennungen erhalten.

Wenn Sie auf „Akzeptieren“ klicken, setzt Google Analytics Cookies (_ga und _ga_*) und erfasst pseudonyme Nutzungsdaten wie die aufgerufenen Seiten, Ihren ungefähren Standort sowie Browser- und Gerätetyp. Google handelt dabei als Auftragsverarbeiter dieser Daten und kann sie in Länder außerhalb Ihres Landes übermitteln.

Hosting

Die Website wird auf GitHub Pages gehostet. GitHub kann technische Daten wie Ihre IP-Adresse protokollieren, wenn Ihr Browser eine Seite anfordert, wie in der Datenschutzerklärung von GitHub beschrieben.

Links, QR-Codes und andere Websites

QR-Codes werden in Ihrem Browser erzeugt. Die Schaltfläche „Link testen“ öffnet die eingegebene Adresse in einem neuen Tab, sodass die geöffnete Website Ihren Besuch sieht. Wir sehen ihn nicht.

Ihre Rechte und Kontakt

Sie können die Analyse unten jederzeit akzeptieren oder ablehnen. Je nach Wohnort haben Sie möglicherweise das Recht auf Auskunft, Berichtigung oder Löschung personenbezogener Daten sowie auf Widerspruch gegen deren Verarbeitung. Da wir weder Ihren Text erfassen noch Sie identifizieren, richten Sie die meisten Anfragen zu Analysedaten am besten an Google.

Fragen oder Anliegen: Eröffnen Sie ein Issue unter github.com/text-to-link/text-to-link.github.io/issues. Ändert sich diese Erklärung, wird das obige Datum aktualisiert.

Ihre Auswahl zur Analyse

Legen Sie fest, ob Google Analytics Cookies speichern und Nutzungsdaten erfassen darf. Sie können dies jederzeit ändern.
