منشئ الروابط من النص

حوّل أي نص إلى رابط قابل للنقر بسهولة. احصل على كود HTML أو Markdown أو BBCode، واربط مباشرة بنص مميز داخل الصفحة، وأنشئ رمز QR مجاناً في متصفحك.

أنشئ رابطاً مفرداً من النص والعنوان. لست متأكداً كيف تبدأ؟ جرّب نموذجاً جاهزاً.

الصق أي نص: سيتحول كل رابط داخله إلى ارتباط تشعبي قابل للنقر.

تحويل أسطر متعددة إلى روابط دفعة واحدة. رابط واحد في كل سطر بصيغة "نص | رابط".

جرّب نموذجاً:

اكتب في كل سطر "نص | رابط" أو الرابط فقط. سيتم تخطي الأسطر التي تحتوي على روابط غير صالحة.

معاينة مباشرة

يعمل بالكامل داخل متصفحك. لا يتم رفع نصوصك أو روابطك إلى أي خادم أبداً.

كيفية تحويل النص إلى رابط

  1. أدخل نص الرابطاكتب الكلمات التي سيراها الزائر وينقر عليها، مثل "قراءة المقال كاملاً".
  2. الصق عنوان الرابطأضف عنوان الموقع. سنضيف https:// تلقائياً إذا كان مفقوداً ويمكننا إزالة معاملات التتبع.
  3. اختر الصيغة وانسخاختر HTML أو Markdown أو BBCode أو reST أو AsciiDoc أو Slack أو Textile أو Org، ثم انسخ الكود أو انسخ كرابط منسق.

أداة مجانية لإنشاء الروابط من النصوص

Text to Link أداة مجانية لتحويل النصوص إلى روابط تشعبية. اكتب الكلمات التي ترغب في إظهارها، والصق العنوان، واحصل فوراً على رابط جاهز بصيغة HTML أو Markdown أو BBCode أو reStructuredText أو AsciiDoc أو Slack أو Textile أو Org-mode. مثالي للتدوينات ورسائل البريد والمنتديات والتوثيق البرمجي.

تتيح لك الأداة إضافة تلميح (title)، والفتح في علامة تبويب جديدة، وإضافة وسوم nofollow أو sponsored أو ugc، والتخلص من معاملات utm_، ونسخ النتيجة كنص منسق يمكن لصقه مباشرة في Gmail أو Google Docs أو Notion أو Slack.

تحتاج إلى عدة روابط؟ الصق فقرة كاملة في وضع تحويل العناوين، أو استخدم وضع قائمة الروابط لتحويل أسطر "نص | رابط" إلى قائمة HTML منسقة. كل شيء يتم محلياً في متصفحك للحفاظ التام على خصوصيتك.

كيفية إنشاء رابط لفقرة مميزة داخل صفحة ويب

روابط النصوص المميزة (Text Fragment Links) تتيح فتح صفحة الويب والتمرير تلقائياً إلى فقرة معينة مع تمييزها بلون بارز. افتح الخيارات المتقدمة، وحدد "تمييز نص محدد داخل الصفحة" واكتب العبارة، وستضيف الأداة صيغة #:~:text= إلى الرابط.

لتمييز فقرة طويلة، املأ حقل "حتى": سيقوم المتصفح بتمييز كل النص بين الكلمات الأولى والأخيرة. وإذا كانت الكلمات مكررة في الصفحة، فاستخدم المطابقة الدقيقة لإضافة الكلمات السابقة أو اللاحقة.

تعمل الروابط المميزة في Chrome وEdge وSafari 16.1+ وFirefox 131+. وفي المتصفحات الأخرى، يُفتح الرابط بشكل طبيعي دون تمييز.

https://example.com/article#:~:text=quick%20brown,lazy%20dog

الأسئلة الشائعة

كيف أقوم بتحويل النص إلى رابط تشعبي؟

اكتب نص الرابط، والصق العنوان، ثم اختر HTML أو Markdown أو غيرها واضغط على نسخ. يصبح النص هو الجزء القابل للنقر.

ما الفرق بين روابط HTML وMarkdown وBBCode؟

تُستخدم روابط HTML في صفحات الويب والبريد الإلكتروني، وروابط Markdown على GitHub وReddit وNotion، وروابط BBCode في منتديات الحوار.

كيف أنشئ رابطاً ينقل القارئ إلى نص محدد ومظلل في الصفحة؟

افتح الخيارات المتقدمة، واكتب العبارة في قسم "تمييز نص محدد داخل الصفحة" وانسخ النتيجة. سينتهي الرابط بـ #:~:text= مع النص المحدد.

هل يمكنني إزالة معاملات utm والتتبع من الرابط؟

نعم. اختر من الخيارات المتقدمة "إزالة معاملات التتبع فقط" لحذف utm_* وfbclid وgclid، أو احذف كل شيء بعد علامة الاستفهام.

كيف ألصق رابطاً منسقاً وقابلاً للنقر في بريد Gmail أو Google Docs؟

اضغط على "نسخ كرابط منسق" ثم الصقه. سيظهر النص كعنوان أزرق قابل للنقر دون الحاجة لكتابة أكواد.

هل يمكن فتح الأداة ببيانات معبأة مسبقاً؟

نعم. يمكنك تضمين المعاملات في العنوان: ?url=https://example.com&text=رابطي&fmt=markdown. كما يمكنك تثبيت الموقع كتطبيق على الهاتف.

هل يمكنني إنشاء رمز QR للرابط الخاص بي؟

نعم. انقر على "رمز QR" أسفل النتيجة، وامسحه للتأكد منه ثم حمله بصيغة SVG أو PNG. يتم إنشاؤه بالكامل داخل متصفحك.

هل تعمل الأداة دون اتصال بالإنترنت؟

نعم. بعد زيارتك الأولى يحفظ المتصفح الموقع في الذاكرة المؤقتة، مما يمكنك من إنشاء الروابط دون اتصال بالإنترنت.

هل الأداة مجانية وآمنة للخصوصية؟

نعم. مجانية بالكامل، لا تتطلب تسجيلاً وتعمل محلياً داخل المتصفح: لا يتم إرسال بياناتك أو نصوصك إلى خوادمنا مطلقاً.
