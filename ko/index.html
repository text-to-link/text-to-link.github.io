텍스트 링크 생성기

모든 텍스트를 클릭 가능한 링크로 변환하세요. HTML, 마크다운, BBCode 형식과 웹페이지 내 텍스트 강조 링크, QR 코드를 브라우저에서 무료로 생성할 수 있습니다.

텍스트와 URL로 단일 링크를 생성합니다. 어떻게 시작할지 모르겠다면 예시를 클릭해보세요.

문장을 붙여넣으면 포함된 모든 웹 주소가 클릭 가능한 링크로 즉시 변환됩니다.

여러 줄을 한 번에 링크로 변환합니다. 한 줄에 "텍스트 | URL" 형식으로 작성하세요.

예시 체험하기:

한 줄마다 "텍스트 | URL" 형식으로 입력하거나 URL만 입력하세요. 유효하지 않은 URL이 있는 줄은 건너뜁니다.

텍스트를 링크로 변환하는 방법

  1. 링크 텍스트 입력방문자가 화면에서 보고 클릭할 문구를 입력하세요 (예: "기사 전문 읽기").
  2. URL 주소 입력웹 주소를 입력하세요. https://가 빠진 경우 자동으로 추가되며 추적 파라미터도 정리할 수 있습니다.
  3. 형식 선택 후 복사HTML, 마크다운, BBCode, reST, AsciiDoc, Slack, Textile, Org 중 원하는 형식을 선택해 코드를 복사하거나 서식 있는 링크로 복사하세요.

무료 텍스트 하이퍼링크 생성 도구

Text to Link는 텍스트를 하이퍼링크로 손쉽게 만들어 주는 무료 도구입니다. 표시할 단어와 웹 주소를 입력하면 HTML, Markdown, BBCode, reStructuredText, AsciiDoc, Slack, Textile, Org-mode 등 다양한 형식의 링크 코드를 즉시 얻을 수 있습니다. 블로그 글, 이메일, 포럼 서명, 기술 문서에 적합합니다.

제목 속성 추가, 새 탭 열기 설정, nofollow/sponsored/ugc 속성 지정, utm_ 등 불필요한 마케팅 추적 파라미터 제거를 지원합니다. 또한 Gmail, Google Docs, Notion, Slack 등에 바로 붙여넣을 수 있는 클릭 가능한 텍스트 형식으로도 복사할 수 있습니다.

여러 링크를 한 번에 처리해야 하나요? "URL 자동 링크 변환" 모드에서 문단 전체를 붙여넣거나 "대량 링크 생성" 모드를 사용하여 여러 줄의 "텍스트 | URL"을 깔끔한 HTML 리스트로 손쉽게 변환해 보세요. 모든 작업이 브라우저 내부에서 실행되어 개인정보가 철저히 보호됩니다.

웹페이지 내 특정 텍스트를 강조하는 링크 만들기

텍스트 프래그먼트(Text Fragment) 링크를 사용하면 웹페이지를 열었을 때 원하는 문장 위치로 자동 스크롤되고 노란색 등으로 강조 표시됩니다. 고급 옵션을 열고 "페이지 내 텍스트 강조 표시"에 문구를 입력하면 URL 뒤에 #:~:text= 규칙이 자동으로 추가됩니다.

긴 문장을 지정하려면 "종료 텍스트"를 함께 입력하세요. 시작 단어부터 끝 단어까지의 모든 영역이 강조됩니다. 동일한 문구가 페이지에 여러 번 등장한다면 "문맥 정확히 일치"를 이용해 앞뒤 단어를 추가로 지정할 수 있습니다.

이 기능은 Chrome, Edge, Safari 16.1+, Firefox 131+에서 작동합니다. 지원하지 않는 브라우저에서도 원본 페이지는 정상적으로 열립니다.

https://example.com/article#:~:text=quick%20brown,lazy%20dog

자주 묻는 질문

텍스트를 링크로 어떻게 변환하나요?

링크 텍스트를 입력하고 URL을 붙여넣은 뒤, HTML이나 마크다운 등 원하는 형식을 선택하고 '복사'를 누르면 됩니다.

HTML, 마크다운, BBCode 링크는 어떤 차이가 있나요?

HTML은 일반 웹사이트와 이메일 템플릿, 마크다운은 GitHub, Reddit, Notion 및 개발 문서, BBCode는 인터넷 포럼 게시판에 주로 쓰입니다.

웹페이지 내 특정 글자를 강조하는 링크는 어떻게 만드나요?

고급 옵션의 '페이지 내 텍스트 강조 표시'에 원하는 문구를 입력하고 링크를 복사하세요. URL 끝에 #:~:text=가 붙어 지원 브라우저에서 자동 강조됩니다.

URL에서 utm 등의 추적 파라미터를 지울 수 있나요?

네. 고급 옵션에서 '추적 파라미터만 제거'를 선택하면 utm_*, fbclid, gclid 등의 마케팅 추적 코드를 말끔히 제거할 수 있습니다.

Gmail이나 Google Docs에 링크가 걸린 텍스트를 바로 넣으려면?

'서식 있는 링크로 복사'를 누른 후 붙여넣으세요. 별도의 코드 수정 없이 클릭 가능한 파란색 링크 형태로 깔끔하게 입력됩니다.

URL 파라미터로 입력값을 미리 채워서 열 수 있나요?

네. 주소창에 ?url=https://example.com&text=내링크&fmt=markdown 처럼 전달할 수 있으며 스마트폰에서는 앱으로 설치하여 공유하기도 가능합니다.

생성한 링크의 QR 코드도 만들 수 있나요?

네. 결과 아래의 'QR 코드' 버튼을 누르면 브라우저에서 즉시 QR 코드가 생성되며 SVG나 PNG 이미지로 다운로드할 수 있습니다.

인터넷이 연결되지 않은 오프라인에서도 작동하나요?

네. 최초 방문 후 사이트 리소스가 브라우저 캐시에 저장되므로 네트워크 연결 없이도 링크 변환 기능을 계속 사용할 수 있습니다.

무료 도구인가요? 개인정보는 안전한가요?

네. 완전 무료이며 회원가입이 필요 없습니다. 모든 변환이 사용자의 브라우저 내에서만 실행되므로 입력한 데이터가 서버로 전송되지 않습니다.
