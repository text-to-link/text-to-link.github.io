개인정보 처리방침

최종 업데이트: 2026-10-29

요약

Text to Link는 전적으로 브라우저에서 실행됩니다. 입력한 텍스트와 URL은 기기 내부에서만 처리되며 서버로 전송되지 않습니다. 계정 생성이나 광고가 없습니다.

기기에 저장되는 항목

브라우저는 원활한 이용을 위해 테마 설정 (ttl-theme), 텍스트를 제외한 출력 형식 설정 (ttl-settings), 데이터 분석 동의 상태 (ttl-consent)를 로컬에 저장합니다.

또한 인터넷 연결 없이도 동작할 수 있도록 Service Worker 캐시에 사이트 파일이 저장됩니다. 브라우저 설정에서いつでも 사이트 데이터를 삭제할 수 있습니다.

데이터 분석

방문 통계 및 도구 이용 현황을 파악하기 위해 Google Analytics 4를 사용합니다. 입력된 텍스트나 URL은 일절 수집하지 않으며 광고 기능은 비활성화되어 있습니다.

분석용 저장은 기본적으로 거부 상태입니다. '동의'를 클릭하기 전에는 분석 쿠키가 생성되지 않습니다. 스크립트는 googletagmanager.com에서 로드됩니다.

동의를 누르면 Google Analytics가 쿠키 (_ga, _ga_*)를 설정하고 방문 페이지, 대략적인 지역, 기기 종류 등의 비식별 사용 데이터를 수집합니다.

호스팅 환경

본 사이트는 GitHub Pages를 통해 호스팅됩니다. 페이지 요청 시 GitHub 정책에 따라 IP 주소 등의 기술적 접속 로그가 기록될 수 있습니다.

외부 링크 및 QR 코드

QR 코드는 브라우저 내부에서 실시간으로 생성됩니다. '링크 테스트' 버튼은 새 탭에서 대상 사이트를 열기 때문에 해당 웹사이트에는 일반적인 방문 기록이 남게 됩니다.

이용자의 권리 및 문의

데이터 분석 동의 여부는 아래에서 언제든지 변경할 수 있습니다. 관련 법률에 따라 개인정보 열람이나 삭제를 요구할 권리가 있을 수 있습니다.

문의 사항이나 의견은 github.com/text-to-link/text-to-link.github.io/issues 에 등록해 주세요. 방침 변경 시 상단의 날짜가 갱신됩니다.

데이터 분석 설정 관리

Google Analytics의 쿠키 저장 및 통계 수집 허용 여부를 선택하세요. 이 설정은 언제든지 변경 가능합니다.
