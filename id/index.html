Cara mengubah teks menjadi link

  1. Masukkan teks linkKetik kata yang akan dilihat dan diklik orang, contoh: "Baca artikel selengkapnya".
  2. Tempel URLMasukkan alamat web. Kami menambahkan https:// jika belum ada dan dapat menghapus parameter pelacakan.
  3. Pilih format dan salinPilih HTML, Markdown, BBCode, reST, AsciiDoc, Slack, Textile, atau Org, lalu salin kodenya atau salin sebagai link kaya.

Pembuat link teks gratis

Text to Link adalah alat pembuat link teks gratis. Masukkan kata yang ingin ditampilkan, tempel alamat web, dan dapatkan link siap pakai dalam format HTML, Markdown, BBCode, reStructuredText, AsciiDoc, Slack, Textile, atau Org-mode. Cocok untuk posting blog, email, tanda tangan forum, dan profil media sosial.

Alat ini berfungsi sebagai generator teks link, generator URL, dan pembuat link artikel: tambahkan judul, buka di tab baru, tandai sebagai nofollow, sponsored, atau ugc, bersihkan parameter utm_, dan salin sebagai link yang dapat diklik di Gmail, Google Docs, Notion, atau Slack.

Perlu banyak link? Tempel satu paragraf penuh dalam mode Jadikan URL dapat diklik, atau gunakan Daftar link untuk mengubah baris "teks | url" menjadi daftar HTML. Semuanya berjalan lokal di browser Anda untuk privasi penuh.

Cara membuat link ke teks yang disorot di halaman

Link teks sorot (text fragment link) membuka halaman web, menggulir ke bagian tertentu, dan menandainya. Buka Opsi lanjutan, temukan "Sorot teks di halaman", masukkan kata yang tepat, dan generator akan menambahkan bagian #:~:text= ke URL Anda.

Untuk menyorot bagian yang panjang, isi bidang "sampai": browser akan menandai dari kata awal hingga akhir. Jika kata yang sama muncul lebih dari sekali, gunakan Pencocokan persis untuk menambahkan teks tepat sebelum atau sesudahnya.

Link dengan sorotan berfungsi di Chrome, Edge, Safari 16.1+, dan Firefox 131+. Di browser lain, halaman tetap terbuka normal tanpa sorotan teks.

https://example.com/article#:~:text=quick%20brown,lazy%20dog

Pertanyaan yang sering diajukan

Bagaimana cara mengubah teks menjadi link?

Ketik teks link, tempel URL, pilih format HTML, Markdown, atau lainnya, lalu klik Salin. Teks tersebut akan menjadi bagian yang dapat diklik.

Apa perbedaan antara link HTML, Markdown, dan BBCode?

Link HTML digunakan di situs web dan template email, Markdown di GitHub, Reddit, Notion, dan dokumentasi, sedangkan BBCode di forum diskusi.

Bagaimana cara menautkan ke teks yang disorot di halaman web?

Buka Opsi lanjutan, ketik kata di bawah "Sorot teks di halaman", lalu salin hasilnya. Link akan berakhiran #:~:text= diikuti teks Anda.

Bisakah saya menghapus parameter utm dan pelacak lainnya dari URL?

Bisa. Di Opsi lanjutan, pilih "Hapus pelacakan saja" untuk menghapus utm_*, fbclid, gclid, atau hapus semua parameter setelah tanda tanya.

Bagaimana cara menempel link yang dapat diklik ke Gmail atau Google Docs?

Klik "Salin sebagai link kaya", lalu tempel. Teks akan langsung dapat diklik tanpa perlu mengedit kode.

Bisakah generator dibuka dengan data yang sudah terisi otomatis?

Bisa. Tambahkan parameter ke alamat web: ?url=https://example.com&text=Link%20Saya&fmt=markdown. Di ponsel pintar, Anda juga bisa memasangnya sebagai aplikasi.

Bisakah saya membuat kode QR untuk link saya?

Bisa. Klik "Kode QR" di bawah hasil, pindai untuk menguji, dan unduh dalam format SVG atau PNG. Kode QR dibuat langsung di browser Anda.

Apakah alat ini berfungsi secara offline?

Ya. Setelah kunjungan pertama, situs ini disimpan oleh browser Anda sehingga Anda dapat membuat link tanpa koneksi internet.

Apakah alat ini gratis dan menjaga privasi?

Ya. Sepenuhnya gratis, tanpa perlu mendaftar, dan diproses langsung di browser Anda: data Anda tidak pernah dikirim ke server.
