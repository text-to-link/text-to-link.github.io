Kebijakan Privasi

Terakhir diperbarui: 2026-10-29

Ringkasan

Text to Link berjalan di browser Anda. Teks dan URL yang Anda masukkan diproses langsung di perangkat Anda dan tidak pernah dikirim ke server. Tanpa akun dan tanpa iklan.

Apa yang disimpan di perangkat Anda

Browser Anda menyimpan data kecil untuk situs ini: preferensi tema (ttl-theme), format dan opsi tanpa teks Anda (ttl-settings), dan pilihan persetujuan analitik (ttl-consent).

Situs ini juga disimpan dalam cache service worker browser Anda agar dapat diakses tanpa koneksi internet. Anda dapat menghapusnya kapan saja melalui pengaturan browser.

Analitik

Kami menggunakan Google Analytics 4 untuk menghitung kunjungan dan memahami fitur yang dibutuhkan. Data teks atau URL Anda tidak pernah dikirim. Fitur iklan dinonaktifkan.

Penyimpanan analitik ditolak secara default. Sebelum Anda mengklik Terima, tidak ada cookie analitik yang disetel. Tag Google dimuat dari googletagmanager.com.

Jika Anda mengklik Terima, Google Analytics menyetel cookie (_ga dan _ga_*) dan mengumpulkan data penggunaan anonim seperti halaman yang dikunjungi dan jenis perangkat.

Hosting

Situs ini di-hosting di GitHub Pages. GitHub dapat mencatat data teknis seperti alamat IP Anda saat browser meminta halaman, sebagaimana dijelaskan dalam pernyataan privasi GitHub.

Link, kode QR, dan situs pihak ketiga

Kode QR dibuat langsung di browser Anda. Tombol Uji link membuka alamat di tab baru, sehingga situs yang dituju akan melihat kunjungan Anda. Kami tidak dapat melihatnya.

Hak Anda dan kontak

Anda dapat menerima atau menolak analitik di bawah ini kapan saja. Bergantung pada lokasi Anda, Anda mungkin memiliki hak untuk mengakses atau menghapus data pribadi.

Pertanyaan atau permintaan: buat issue di github.com/text-to-link/text-to-link.github.io/issues. Tanggal di atas akan diperbarui jika ada perubahan kebijakan.

Pilihan analitik Anda

Pilih apakah Google Analytics diizinkan menyimpan cookie dan mengumpulkan data penggunaan. Anda dapat mengubah pilihan ini kapan saja.
