隐私政策

最近更新日期: 2026-10-29

概览

Text to Link 完全在您的浏览器中运行。您输入的文字和网址均在本地处理，绝不会发送到任何服务器。本站无账户系统，亦无广告。

本地存储内容

为了保障基本使用体验，浏览器会在本地保存少量设置：您的主题模式 (ttl-theme)、输出格式偏好及选项（不含您的文本内容，ttl-settings）以及数据分析许可状态 (ttl-consent)。

此外，Service Worker 缓存会保存网站离线文件以便在无网络时访问。您可以随时通过清理浏览器网站数据完全移除它们。

数据统计分析

我们使用 Google Analytics 4 了解网站访问量和功能受欢迎程度。它绝不会获取您输入的文本或网址。所有个性化广告与商业推广功能均已强制关闭。

默认情况下拒绝分析存储。在您主动点击“接受”之前，系统不会设置任何统计 Cookie。Google 脚本加载自 googletagmanager.com。

如您点击“接受”，Google Analytics 会写入 Cookie (_ga 及 _ga_*) 并收集去标识化的匿名统计信息，例如访问页面、大致地理区域以及浏览器和设备类型。

网络托管

本站托管于 GitHub Pages。当浏览器请求页面时，GitHub 可能会根据其隐私声明记录必要的网络技术日志（如 IP 地址）。

外链与二维码安全

二维码均在您的本地浏览器实时生成。“测试链接”按钮会在新标签页打开您输入的网址，目标网站会记录您的常规网页访问，而我们无法查看该行为。

您的权利与联系方式

您可以随时在下方重新选择接受或拒绝数据分析。根据您所在地区的法律法规，您可能享有个人数据访问、更正或删除的权利。

如有任何疑问或意见反馈，欢迎在 github.com/text-to-link/text-to-link.github.io/issues 提交 Issue。本政策如有调整，上方的更新日期将同步变更。

管理您的分析偏好

选择是否允许 Google Analytics 存储 Cookie 并收集匿名使用数据。您可以随时更改此设置。
