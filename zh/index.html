免费便捷的文本超链接制作工具

Text to Link 是一个免费的文本转超链接工具。只需输入要显示的文字和目标网址，即可立即生成适用于 HTML、Markdown、BBCode、reStructuredText、AsciiDoc、Slack、Textile 或 Org-mode 的标准链接。非常适合博客文章、电子邮件、论坛签名、技术文档和社交媒体主页。

它集成了文本链接生成、网址文本转换和文章链接定位功能：可自定义标题、设置新标签页打开、添加 nofollow、sponsored 或 ugc 属性，自动剔除 utm_ 等冗余追踪参数，并可一键复制为可直接粘贴至邮件与在线文档的富文本格式。

需要批量处理？在“一键转换链接”模式下粘贴整段文字即可自动解析所有网址；在“批量链接”模式下则可将多行“文字 | 网址”一键转为美观的 HTML 列表。所有运算均在本地浏览器完成，绝无泄露隐私之忧。

如何制作直达并高亮页面文字的链接

高亮定位链接（Text Fragment Link）可在打开网页时自动平滑滚动到指定段落并将其高亮显示。展开“高级选项”，在“高亮页面中的文本”输入框中填入目标词句，生成器便会在网址末尾追加 #:~:text= 规则。

如需高亮较长语段，可填写“结束文字”：浏览器将完整高亮起止之间的全部文字。若目标词句在文中多次出现，可使用“精确匹配上下文”指定其前后的词句进行辅助定位。

该功能获得 Chrome、Edge、Safari 16.1+ 及 Firefox 131+ 原生支持。在其他浏览器中访问时仍能正常打开原页面，只是不显示高亮。

https://example.com/article#:~:text=quick%20brown,lazy%20dog

常见问题解答

如何把普通文本转成超链接？

输入想要展示的文字，粘贴网址，选择 HTML、Markdown 或其他格式，点击“复制”即可。文字就会成为可点击的链接主体。

HTML、Markdown 和 BBCode 链接有什么区别？

HTML 链接主要用于网页和邮件模板；Markdown 链接广泛用于 GitHub、Reddit、Notion 及技术文档；BBCode 链接常见于论坛发帖。

怎样制作直接定位并高亮网页文字的链接？

展开高级选项，在“高亮页面中的文本”填入需标记的词句并复制生成的链接。链接末尾带有 #:~:text=，支持的浏览器会自动滚动并高亮该文本。

可以自动去除 URL 中的 utm 等追踪参数吗？

可以。在高级选项中选择“仅去除追踪参数”，即可一键清除 utm_*、fbclid、gclid 等常见追踪标识，或彻底清除问号后的所有参数。

如何将可点击链接直接粘贴到邮件或文档中？

点击“复制为富文本链接”后直接粘贴即可。文字会自带超链接，无需手动编辑代码。

可以通过网址参数预先填好内容吗？

可以。在网址后追加参数即可：?url=https://example.com&text=我的链接&fmt=markdown。在手机上还可以将本站安装为应用并直接分享网页至本工具。

可以为链接生成二维码吗？

可以。点击结果下方的“二维码”，扫码即可测试并支持免费下载 SVG 或 PNG 图片，全过程在本地浏览器完成。

该工具支持离线使用吗？

支持。首次访问后，Service Worker 会将页面缓存在本地，即使没有网络也能随时打开生成链接。

使用此工具是否安全并保护隐私？

是的。工具完全免费且免注册，所有处理都在浏览器内本地进行，您输入的文本和网址绝不会上传到服务器。
